## ⚒️ 대장간 사용 설명서

1. **한입 크기로 벼린다** — 버스 한 정거장 사이에도 한 판. 작을수록 단단합니다.

2. **일단 던진다** — 완벽한 게임보다 오늘 나온 게임. 던지고, 반응 보고, 다시 달굽니다.

3. **재미가 왕이다** — 재미없으면 그래픽이 아무리 예뻐도 용광로행. 그래서 용광로가 자꾸 살찝니다.

## 🧪 게임이 나오는 법

```text
[“그거 웃긴데?”]
        ↓
[2주 안에 손에 쥐기]
        ↓
[다 같이 웃을 때까지 두드리기]
        ↓
      YEET!
```

완벽해질 때까지 기다리면 출시일이 `∞`가 되더라고요.
